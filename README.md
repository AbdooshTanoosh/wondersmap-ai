# WondersMap AI
An intelligent bilingual (English/Arabic) travel planning platform.
## Technology Stack
- React + TypeScript
- Python + FastAPI
- PostgreSQL
- OpenAI + LangGraph
- Docker
- Microsoft Azure
## Features
- AI-powered trip planning
- English and Arabic interfaces (LTR/RTL)
- Interactive maps
- Travel budget management
- Personalized itineraries

Under development.
